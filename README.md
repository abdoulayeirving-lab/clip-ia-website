# CLIP IA — site officiel

Site d’information public de CLIP IA, composé de pages HTML statiques.

## Pages

- `index.html` — présentation du logiciel
- `terms.html` — conditions d’utilisation
- `privacy.html` — politique de confidentialité

## Publier avec GitHub Pages

1. Créez un dépôt public nommé `clip-ia-website` et ajoutez un README.
2. Ajoutez ces quatre fichiers à la racine du dépôt.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, la branche `main` et le dossier `/ (root)`, puis enregistrez.
4. Attendez la fin du déploiement GitHub Pages. L’adresse du site de projet sera normalement `https://abdoulayeirving-lab.github.io/clip-ia-website/`.
5. Vérifiez la page d’accueil ainsi que les pages `/terms.html` et `/privacy.html` avant de saisir les URL dans TikTok for Developers.

Le site ne contient aucun secret de l’application. Les informations juridiques sont un brouillon produit à partir du fonctionnement actuel du logiciel et doivent être vérifiées par l’éditeur, notamment avant une soumission à TikTok. Les URL restent indisponibles avant la création du dépôt et l’activation effective de GitHub Pages.
